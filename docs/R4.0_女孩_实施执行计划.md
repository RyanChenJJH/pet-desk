# 女孩 R4.0 实施执行计划

> **原始需求与背景回溯**：
> - 提出时间：2026-09-15
> - 业务场景：用户先提出“请利用项目下的开源项目pet-forge，采用**APNG 路线**  创建R4_GIRL下的动画素材。动画采用R4_GIRL下的图片中的角色。先执行R4.0方案和计划。然后再按照方案和计划执行。”随后改为“我改成SVG的路线，看下如何将文件下的那张`GIRL.png` 图片，做成动画”，并对“参考图语义重绘 SVG 母版 + CSS 状态动画”的建议回复“同意”。
> - 已拍板技术决策：采用全 SVG 路线；以 `work_space/R4_GIRL/GIRL.png` 为唯一角色参考图；不走 APNG；不把 PNG 自动描摹结果直接当作动画母版；以分层语义 SVG 母版作为唯一真实源；首版交付 Clawd-on-Desk 可加载的 6 个核心状态。
> - 对接运行时：Clawd-on-Desk (`theme.json` Schema v1)
> - 交付目标：`work_space/R4_GIRL/`

## 阶段 1：目录与文档

目标：

- 建立 `R4_GIRL` 五级工程流水线。
- 写入 R4.0 设计与技术方案。
- 写入 R4.0 实施执行计划。

验收：

- 文档位于 `work_space/docs/`。
- 角色目录包含 `00_reference/`、`01_master/`、`02_forge/`、`03_export/`、`theme/assets/`。

## 阶段 2：分层母版

目标：

- 依据 `GIRL.png` 提取角色识别特征。
- 绘制 `girl-master.svg` 静态分层母版。
- 保留 `#shadow-js`、`#body-js`、`#eyes-js` 挂点。

验收：

- 母版为纯 SVG，无脚本、无外链。
- 造型能识别为参考图中的女孩角色。
- 不凭空添加全身腿部或新角色设定。

## 阶段 3：状态动画

目标：

- 从母版派生 6 个状态 SVG。
- 每个 SVG 自包含 CSS 动画。
- `idle-follow.svg` 接入眼睛/身体/投影运行时挂点。

验收：

- `theme/assets/` 包含：
  - `idle-follow.svg`
  - `working.svg`
  - `thinking.svg`
  - `notification.svg`
  - `sleeping.svg`
  - `roam.svg`
- 循环动画首尾关键帧闭合。
- `roam.svg` 保持面朝右的桌面漫步约定。

## 阶段 4：主题配置与预览

目标：

- 编写 `theme/theme.json`。
- 编写 `02_forge/preview-all-states.html`，用于本地快速查看全部状态。
- 归档导出产物到 `03_export/`。

验收：

- `theme/` 根目录仅包含 `theme.json` 与 `assets/`。
- `theme.json` 不使用非法 `fallbackTo`。
- `visibleHeightRatio` 为 `0.42`，`baselineBottomRatio` 为 `0.05`。

## 阶段 5：安装与版本同步

目标：

- 提供 `install-to-clawd.ps1` 同步脚本。
- 生成导入包。
- 完成 Git 提交与推送。

验收：

- 主题可复制到 Clawd-on-Desk themes 目录。
- `work_space` 仓库提交语义化 commit。
- 推送到 `origin main`。
