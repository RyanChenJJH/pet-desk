# R2.0 阶段：闹钟机器人（Clock Robot）桌面宠物设计与技术方案

> **原始需求与背景回溯**：
> - **提出时间**：2026-09-15
> - **业务背景**：`pet-forge` 为开源动画制作工作坊，`clawd-on-desk` 为本地桌面宠物运行时。当前需要在 `work_space` 下制作个人定制桌宠。已有 R1 机器猫（`work_space/R1_doraemon`），现于 `work_space/R2_clock` 开发全新动画角色——“闹钟机器人”。
> - **已拍板技术与设计决策**：
>   1. **角色造型**：采用【经典复古双耳发条机器人】风格（圆形金属钟体 + 头顶双铜铃与敲击小锤 + 机械短腿与活动手臂）。
>   2. **表盘与眼球跟随**：采用【拟人表盘一体化】方案（钟面正中为大眼睛对接 `#eyes-js` 光标跟随，周围搭配点状刻度与慢转指针）。
>   3. **交付范围**：聚焦【MVP 核心 6 状态】（`idle`, `roam`, `working`, `thinking`, `notification`, `sleeping`）。
>   4. **技术路线**：严格遵循【全 SVG 路线】（自包含 SVG、纯内联 CSS `@keyframes`、严禁 `<script>`、无外部网络字体或图像依赖）。
>   5. **文件命名**：采用【标准下划线中文命名】（`docs/R2.0_闹钟机器人_设计与技术方案.md` 与 `docs/R2.0_闹钟机器人_实施执行计划.md`），统一归档于 `work_space/docs/`。
> - **对接运行时**：Clawd-on-Desk (`theme.json` Schema v1)
> - **交付目标**：`work_space/R2_clock/`

## 1. 方案概述与设计哲学

本方案依据 `pet-forge` 动画工作流及 `clawd-on-desk` 桌宠系统规范，专为用户定制打造具有机械复古美感、生动趣味性的**闹钟机器人**桌面宠物。

### 1.1 核心技术特性
- **全纯净矢量（Zero Script & Pure Vector）**：100% SVG 1.1 规范，零 JavaScript 运行侵入，完全由 CSS3 `@keyframes` 驱动硬件加速渲染，CPU 占用极低（<0.8%），高分屏 4K/8K 缩放无损。
- **Clawd 光标跟随契约（Eye-Tracking Rig）**：
  - `#eyes-js`：驱动表盘内部的大圆眼球，随着用户鼠标光标平滑转动（偏移范围 2~2.5px）。
  - `#body-js`：接收微幅身体倾角，赋予机械体灵动生命力。
  - `#shadow-js`：接收投影随视角延展拉伸。
- **物理闭环节奏**：A 类循环动画首末帧（0% 与 100%）在变换与透明度上严格一致，无任何卡顿跳变。

## 2. 角色拓扑与分层母版规范 (`clock-master.svg`)

基于 `pet-forge` 分层母版标准，构建统一的坐标系、视觉色板与图层契约。

### 2.1 基础视口与基准坐标
- **`viewBox`**：`-20 -25 50 50`（逻辑尺寸 50×50，中心点偏向 `(5, 0)`，脚底接触地面基准线 `Y = 18`）。
- **`contentBox`**：`{ "x": -8, "y": -12, "width": 26, "height": 30 }`。
- **`centerX`**：`5`，**`baselineY`**：`18`。

## 3. MVP 核心 6 大状态动画设计矩阵

| 状态名 | 文件名 | 动作语义与视觉表现 | 循环类型 | 核心 CSS Keyframes 设计 |
|---|---|---|---|---|
| **`idle`** | `idle-follow.svg` | **标准待机**：机体 3.6s 呼吸起伏，分针慢速滴答微动，小锤微幅呼吸微摆，双眼实时跟随鼠标光标，间隙 4.5s 自然双眨眼。 | 持续循环 (A类) | `@keyframes breathe`, `@keyframes blink`, `@keyframes tick-tock` |
| **`roam`** | `roam.svg` | **漫步巡逻**（朝右）：两只小机械脚踩着钟摆发条节拍交替前后小踏步，双耳铜铃随步调轻快颠簸，背后发条平稳顺时针旋转。 | 持续循环 (A类) | `@keyframes walk-feet`, `@keyframes bell-bob`, `@keyframes windup-turn` |
| **`working`** | `working.svg` | **超频工作**：时针与分针如同齿轮狂转般高速旋转，机械双臂飞速上下交替敲击键盘，头顶双耳铜铃闪耀科技工作微光。 | 持续循环 (A类) | `@keyframes dial-spin-fast`, `@keyframes arm-typing`, `@keyframes glow-pulse` |
| **`thinking`** | `thinking.svg` | **沉思推演**：时间倒流徘徊（分针逆时针微晃），小单手托住表壳底部作思考状，双眼斜向上方注视，头顶浮现机械齿轮疑问气泡。 | 持续循环 (A类) | `@keyframes hand-reverse`, `@keyframes arm-ponder`, `@keyframes bubble-float` |
| **`notification`** | `notification.svg` | **闹铃大作（唤醒/通知）**：中间小锤以超高频在左右双铜铃之间疯狂撞击打铃，钟身整体伴随剧烈震颤与上下微跳，头顶散发声波波纹弧线。 | 持续循环 (A类) | `@keyframes hammer-ring`, `@keyframes alarm-shake`, `@keyframes sound-wave` |
| **`sleeping`** | `sleeping.svg` | **停摆休眠**：发条完全停滞，双腿曲折坐于地面，钟体向右斜靠 12°，双眼呈闭目弧线（`︶ ︶`），头顶缓缓飘起透明“Zzz”字符。 | 持续循环 (A类) | `@keyframes sleep-droop`, `@keyframes zzz-drift` |

## 5. 验收与质量基准

1. **语法与沙箱基线**：
   - 运行静态检查，确认 `theme/assets/*.svg` 中绝对不包含任何 `<script>` 或外链资源。
2. **光标跟随与基准一致性**：
   - `idle-follow.svg` 在浏览器中模拟鼠标移动，`#eyes-js` 平滑运动且边界不溢出表盘。
3. **首尾帧闭环**：
   - 在浏览器中连续观测各状态动画 30 秒以上，无闪跳、卡顿或断帧。
4. **一键同步就绪**：
   - 编写配套的 `install-to-clawd.ps1`，支持自动将主题包同步部署至 Clawd-on-desk 的 `themes/clock-robot` 目录并实时预览。
