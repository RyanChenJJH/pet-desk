## 1. 方案概述与设计哲学

本方案基于 `pet-forge` 动画工作流与 `clawd-on-desk` 桌宠架构，为用户打造专属的**机器猫桌面宠物**。

### 1.1 核心选型与风格定义
- **技术路线**：**纯 SVG + CSS 关键帧动画**。零外部依赖、零 API 成本、无限分辨率无损缩放、CPU 占用极低（<1%）。
- **美学风格**：**经典动漫圆润矢量风**，继承 `apple-precise` 预设规范。
  - 主体采用柔和纯色填充与微阴影，杜绝刺眼的高对比度荧光色。
  - 边缘采用精细平滑的深灰黑描边（`#24292E`，比死黑 `#000000` 更温润现代）。
  - 采用 **三层描边体系**（微光晕 + 主结构线 + 内弧高光），赋予二维角色拟物般的温润质感。
- **动态特性**：
  - **眼球跟随（Eye Tracking）**：利用 Clawd 的 `#eyes-js` 接口，机器猫两颗大圆眼瞳随用户光标全屏平滑转动。
  - **苹果级节奏**：呼吸周期 3.6s 缓周期（0.98~1.02 呼吸幅度），随机眨眼（3~7s 随机间隔 + 10% 双连眨）。

## 2. 角色拓扑与分层母版规范 (`doraemon-master.svg`)

依据 `pet-forge/routes/svg/conventions/layered-master.md`，建立统一的母版坐标系与分层契约。

### 2.1 基础视口与基准坐标
- **`viewBox`**：`-20 -25 50 50`（逻辑宽高 50x50，中心点偏向 `(5, 0)`，脚底基准线 `Y = 18`）。
- **`contentBox`**：`{ "x": -8, "y": -12, "width": 26, "height": 30 }`。
- **`centerX`**：`5`，**`baselineY`**：`18`。

### 2.2 色板规范（Doraemon Palette）
| 部位 | 颜色名称 | 十六进制色值 | 用途与说明 |
|---|---|---|---|
| 头部 / 身体外皮 | Doraemon Blue | `#0096E6` | 经典湛蓝，饱和度适中 |
| 身体背部阴影 | Deep Blue Shadow | `#0077B8` | 用于边缘微妙着色 |

## 5. 验收标准与验证流程 (Runbook)

每个 SVG 文件交付前必须满足：
1. **语法与自包含性**：纯 XML/SVG，无外部 `<script src>`，无外链图片/字体，仅允许标准 CSS `@keyframes`。
2. **眼球跟随校验**：`idle-follow.svg` 必须暴露规范的 `#eyes-js`, `#body-js`, `#shadow-js`。
3. **循环周期测试**：在浏览器内连续循环观察 30 秒以上，呼吸与部件归位无跳变（0% 与 100% 平滑闭环）。
4. **Clawd-on-desk 验证器通过**：运行 `node scripts/validate-theme.js <theme-dir>` 输出全部绿勾通过。
