# Doraemon (机器猫) R1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `work_space/doraemon` 下使用 `pet-forge` 动画规范构建机器猫（哆啦A梦）的 6 个 MVP 核心矢量动画状态，并配置符合 `clawd-on-desk` 规范的自包含主题包，支持鼠标光标眼球跟随。

**Architecture:** 采用纯 SVG + CSS `@keyframes` 架构，依托分层矢量母版 (`doraemon-master.svg`) 保证角色造型一致性；动画文件无外部脚本与网络依赖，符合 Clawd 安全沙箱与高分屏无损渲染要求；通过 `theme.json` 挂载到 Clawd-on-Desk 状态机。

**Tech Stack:** SVG 1.1, CSS3 Animations, Vanilla JS (调参/测试预览), Node.js (Clawd 验证器与安装脚本)。

## Global Constraints

- 所有 SVG 动画文件必须自包含，严禁使用 `<script>` 标签或外部 `<link>` / `<image>` 外链（外部主题在 Clawd-on-desk 中运行时会被清理剥离 script）。
- `idle-follow.svg` 必须严格提供 `#shadow-js`, `#body-js`, `#eyes-js` 元素 ID，且坐标系原点与基准点一致。
- 坐标系统一为 `viewBox="-20 -25 50 50"`，水平中心点约为 `5`，脚底落地基准线为 `Y = 18`。
- 循环动画（A类）首帧与末帧状态必须平滑闭环（0% 与 100% transform 一致）。
