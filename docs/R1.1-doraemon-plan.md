# Doraemon (机器猫) R2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 R1 成果的基础上，为机器猫桌面宠物扩展自由漫步行走、鼠标悬空拖拽与戳碰交互、经典四次元道具彩蛋、完整 4 阶段睡眠过渡链以及 Agent 专属事件状态，完成 15+ 全状态自包含 SVG 资产构建与主题 v2.0 升级。

**Architecture:** 继承 R1 分层母版与苹果精致风动画规范，构建 `gadgets-library.svg` 道具库实现部件解耦复用；使用原生 CSS `@keyframes` 驱动多肢体复合摆动（如自由漫步腿臂交替、悬空挣扎与道具悬浮）；遵循 Clawd Schema v1 注册 `reactions`、`workingTiers`、`idleAnimations` 和 `sleepSequence.mode: "full"`。

**Tech Stack:** SVG 1.1, CSS3 Animations, Node.js (Clawd-on-desk Theme Validator)。

## Global Constraints

- 所有新增 SVG 必须遵守相同坐标系：`viewBox="-20 -25 50 50"`，水平中心线约为 `5`，脚底落地水平线为 `Y = 18`。
- `roam.svg` 必须角色朝右（Facing Right），以便 Clawd-on-desk 运行时向左漫步时自动进行 X 轴镜像变换。
- 零外部依赖，所有道具矢量路径与渐变色板均内联在各个 SVG 文件中。
- 所有动画帧时长与节奏必须与 `R2-doraemon-scheme.md` 契约严格对应。
