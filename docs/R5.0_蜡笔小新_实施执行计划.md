## 全局技术红线与硬约束（Global Constraints）

1. **全 SVG 自包含**：所有 SVG 文件必须是独立自包含的，严禁包含任何 `<script>` 标签或外部 `<link>` / `<img>` 依赖。
2. **光标跟随协议**：`idle-follow.svg` 必须暴露 `#eyes-js`, `#body-js`, `#shadow-js` 元素 ID，且变换基准点与坐标系严格一致。
3. **关键帧 100% 闭环**：所有循环动画（`idle`, `roam`, `working`, `thinking`, `notification`, `sleeping`）的 `@keyframes` `0%` 与 `100%` 必须绝对一致，严禁出现卡顿与瞬跳断层。
4. **漫步方向统一**：`roam.svg` 角色本体必须绘制为面向右侧（Facing Right），以便运行时自动镜像。
5. **固定尺寸基线**：统一居中视口 `viewBox="-25 -25 50 50"`，桌面窗口占比 `visibleHeightRatio: 0.42`，`baselineBottomRatio: 0.05`。
6. **无 BOM UTF-8**：`theme.json` 严禁出现 UTF-8 BOM 字节。
7. **Git 自动化纪律**：开发完毕后自动执行 `git add .`、语义化提交并推送到远端 `main` 分支。
