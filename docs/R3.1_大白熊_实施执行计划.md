>   3. **交付范围**：6 大核心状态（`idle`, `roam`, `working`, `thinking`, `notification`, `sleeping`）。

## Global Constraints

1. **全 SVG 自包含硬性约束**：所有交付产物必须是自包含 SVG，严禁任何 `<script>` 标签或外部 `<link>` / `<image>` 引用。
2. **固定尺寸红线**：`visibleHeightRatio` 必须设为 `0.42`，严禁超过 `0.48`；`contentBox` 严格对齐 `26×28`。
3. **Clawd 光标跟随契约**：`idle-follow.svg` 必须保留 `#eyes-js`, `#body-js`, `#shadow-js`。
4. **漫步面朝右侧**：`roam.svg` 角色本体必须绘制为面向右侧（Facing Right）。
5. **编码硬约束**：`theme.json` 必须保存为纯 UTF-8 无 BOM 格式。
6. **严禁占位符（No Placeholders）**：所有任务与步骤必须包含完整的可执行代码与明确的验证命令。
