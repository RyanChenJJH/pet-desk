# 闹钟机器人（Clock Robot）R2.0 实施执行计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `work_space/R2_clock` 下采用 `pet-forge` 全 SVG 动画标准制作“复古双耳发条闹钟机器人”的 6 大 MVP 核心动画状态，构建符合 `clawd-on-desk` 规范的主题包并提供一键同步部署脚本。

**Architecture:** 采用全纯净自包含 SVG + 内联 CSS `@keyframes` 架构，依托分层矢量母版 (`clock-master.svg`) 保证各部件造型与拓扑一致性；严格对齐 Clawd-on-desk 安全沙箱契约（零 `<script>`、零外部依赖）及光标注视协议（`#eyes-js`, `#body-js`, `#shadow-js`）；通过 `theme.json` 完成与桌面宠物运行时的状态映射。

**Tech Stack:** SVG 1.1, CSS3 Animations (@keyframes), PowerShell 7+, JSON (theme.json Schema v1)。

## Global Constraints

1. **全 SVG 自包含硬性约束**：所有交付产物必须是自包含 SVG，严禁任何 `<script>` 标签或外部 `<link>` / `<image>` 引用。
2. **Clawd 光标跟随接口标准**：`idle-follow.svg` 必须暴露 `#eyes-js`, `#body-js`, `#shadow-js` 元素 ID，基准坐标系严格保持 `viewBox="-20 -25 50 50"`。
3. **动画闭环无跳帧**：所有持续循环状态（A 类动画）的 `@keyframes` 0% 与 100% 变换属性必须绝对一致。
4. **漫步方向统一**：`roam.svg` 角色本体必须绘制为面向右侧（Facing Right）。
5. **严禁占位符（No Placeholders）**：所有任务与步骤必须包含完整的可执行代码与明确的验证命令，杜绝任何 TBD/TODO。

# install-to-clawd.ps1 - 同步闹钟机器人主题包到 Clawd-on-desk
param (
    [string]$ClawdThemeDir = "E:\Work2\AI_Work\tool\clawd-on-desk\clawd-on-desk\clawd-on-desk\themes\clock-robot"
)

$SourceTheme = Join-Path $PSScriptRoot "theme"

Write-Host "🚀 安装 ClockRobot 主题到 Clawd-on-desk" -ForegroundColor Yellow
Write-Host "源路径: $SourceTheme"
Write-Host "目标路径: $ClawdThemeDir"

if (-not (Test-Path $ClawdThemeDir)) {
    New-Item -ItemType Directory -Force -Path $ClawdThemeDir | Out-Null

Copy-Item -Path "$SourceTheme/*" -Destination $ClawdThemeDir -Recurse -Force

Write-Host "✅ 主题同步成功！" -ForegroundColor Green
Write-Host "可在 Clawd-on-desk 运行时中切换至 ClockRobot 主题进行预览。" -ForegroundColor White
