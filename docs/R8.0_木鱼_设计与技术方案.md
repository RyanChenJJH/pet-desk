# 木鱼 R8.0 设计与技术方案（正宗法器整改版）

> **原始需求与背景回溯**：
> - **提出时间**：2026-09-20
> - **业务场景**：`pet-forge` 为开源动画工坊，对接本地桌面宠物运行时 `clawd-on-desk`（`E:\Work2\AI_Work\tool\clawd-on-desk\clawd-on-desk\clawd-on-desk`）。当前需要在 `work_space/R8_wooden_fish/` 目录下完成纯 SVG 路线的“木鱼”桌宠落地。
> - **第一轮实现与用户反馈**：
>   - 原版本采用呆萌拟人 Chibi 风（带大眼睛、圆球躯干），用户体验后提出核心整改意见：
>     1. **造型不像木鱼**：需摒弃低幼圆球，完美还原正宗佛教经典法器木鱼构造；
>     2. **彻底取消眼睛设计**：取消任何拟人化眼部，纯粹呈现木雕法器之庄严古朴与文化禅意；
>     3. **静态展示常态敲击**：待机（`idle`）状态下即为木鱼常态敲击，小木槌有节奏叩击，侧旁伴随敲击浮现显示 “+1”，然后慢慢升腾消散。
> - **已拍板技术决策（第二轮）**：
>   1. **正宗法器构造 + 朱红金边锦缎蒲团**：完美还原传统木鱼经典形制：饱满鱼腹共鸣腔、贯穿侧面的镂空发音横槽（双端带共鸣扩孔）、背部双层立体浮雕鱼鳞云纹、后部卷尾镂空提梁把手；端坐于精致的朱红金边锦缎绣花蒲团上。
>   2. **纯粹法器美学（无眼五官）**：彻底剔除拟人化眼部组件，禁用眼球跟随（`eyeTracking.enabled: false`），采用深色红木/紫檀温润质感。
>   3. **待机常态敲击（1.6s 舒缓安神节奏）**：静态展示（`idle`）常态为小木槌规律叩击木鱼头顶；每次击中时木鱼在蒲团上微沉下陷回弹，侧上方升起半透明金色 “+1” 并袅袅飘散淡出，附带微光金色音波圆环。
>   4. **全 SVG 路线硬约束**：自包含 SVG 格式与纯 CSS3 `@keyframes` 驱动，严禁 `<script>`，零外部网络资源，首尾帧 100% 严格闭环。
>   5. **固定尺寸基线规范**：采用居中视口 `viewBox="-25 -25 50 50"`，地面接触线 `baselineY = 18`，主体可视宽高控制在 26×24，`visibleHeightRatio: 0.40`，`baselineBottomRatio: 0.05`。
>   6. **完整状态矩阵覆盖**：交付 7 大核心状态（`idle`/`idle-follow`, `roam`, `working`, `thinking`, `sleeping`, `notification`, `error`）。
> - **对接运行时**：Clawd-on-Desk (`theme.json` Schema v1)
> - **交付目标**：`work_space/R8_wooden_fish/`

## 1. 角色造型重构与正宗法器美学

### 1.1 核心形制解构（传统大和木鱼 / 经典寺院木鱼）
1. **鱼腹共鸣腔 (Resonance Chamber)**：
   - 形状呈上隆下阔的圆拱形，内部中空扩音。
   - 采用深红木/紫檀木质渐变，质感深沉温润。
2. **镂空发音横槽 (Sound Slit)**：
   - 贯穿正面与侧面的雕空深槽，开口两侧各有一处圆弧扩孔，这是法器音色浑厚悠远的关键物理结构。
3. **背脊鳞纹与浮雕云纹 (Carved Fish Scales & Cloud Motifs)**：
   - 背脊中线上对称雕刻双层立体弧形鳞纹与如意卷云纹，通过阴刻暗槽线与阳刻高光线呈现纯正手雕木质肌理。
4. **环尾提梁把手 (Carved Tail Handle)**：
   - 木鱼后部呈现优美的镂空中空卷尾，构成经典的法器提梁握柄轮廓剪影。
5. **朱红金边锦缎蒲团底座 (Brocade Lotus Cushion)**：
   - 木鱼稳稳置于朱红（`#DC2626` / `#991B1B`）丝绸锦缎蒲团之上，四周镶嵌金黄滚边与如意褶皱，增强视觉重量感与庄严感。
6. **悬浮敲击木槌 (Sacred Wooden Mallet)**：
   - 细长木柄配红布束带，前端包裹圆头木槌，斜悬于木鱼上方精准叩击。
