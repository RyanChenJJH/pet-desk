# 木鱼 R8.0 设计与技术方案

> **原始需求与背景回溯**：
> - **提出时间**：2026-09-20
> - **业务场景**：`pet-forge` 为开源动画制作工作坊，`clawd-on-desk`（本地路径 `E:\Work2\AI_Work\tool\clawd-on-desk\clawd-on-desk\clawd-on-desk`）为桌面宠物运行时。项目下已有 R1~R7 等多款桌宠，当前需要在 `work_space/R8_wooden_fish/` 下，为桌面端定制一个高品质、治愈解压的“木鱼”动画素材。
> - **用户原始诉求**：“采用SVG 路线的方式。在R8_wooden_fish下，制作一个木鱼的动画素材，不要有手和脚。就单纯的木鱼。”
> - **已拍板技术决策**：
>   1. **全 SVG 路线硬约束**：完全使用自包含 SVG 格式与内联 CSS3 `@keyframes` 硬件加速，严禁 `<script>` 标签，严禁外部字体与网络资源，100% 纯净沙箱安全无损。
>   2. **角色拓扑（纯木鱼，无手脚）**：采用【呆萌拟人解压风】。主体为圆润饱满的暖木金檀木鱼，正前方点缀一双灵动大眼睛（接入 `#eyes-js` 支持鼠标跟随互动），被敲击或开心时可眯成月牙笑眼。斜后上方伴随一只小巧圆润的悬浮伴生小木槌（Magic Mallet），作为核心交互敲击部件。
>   3. **漫步移动方式（Hop & Squash）**：无手脚前提下，漫步（`roam`）采用“Q 弹果冻跳跃”模式：向下蓄力压扁至 0.85 -> 弹跳腾空向前跃进 -> 落地伴随软弹果冻回弹，小木槌在后方受惯性跟随起伏。角色造型统一**面朝右侧 (Facing Right)**。
>   4. **核心互动（功德+1 光效）**：沉浸工作（`working`）与提醒（`notification`）状态下，小木槌高频有节奏地叩击木鱼头顶，木鱼惬意眯眼笑颤，头顶不断升腾出半透明金色“功德+1”与佛系光晕音波，治愈解压感拉满。
>   5. **固定尺寸基线规范**：严格恪守 `AGENTS.md` 2.1 规范，采用居中视口 `viewBox="-25 -25 50 50"`，地面接触线 `baselineY = 18`，主体可视宽高控制在 24×20（加光效总高约 26），`visibleHeightRatio: 0.40`（红线范围 0.38~0.44），`baselineBottomRatio: 0.05`。
>   6. **完整状态矩阵覆盖**：交付 7 大核心状态（`idle`/`idle-follow`, `roam`, `working`, `thinking`, `sleeping`, `notification`, `error`）。
> - **对接运行时**：Clawd-on-Desk (`theme.json` Schema v1)
> - **交付目标**：`work_space/R8_wooden_fish/`

## 1. 方案概述与角色设计哲学

传统木鱼作为佛教法器与现代年轻人的“赛博解压神器”，自带“敲木鱼积功德、清心安神”的文化属性。
本方案将传统木雕法器与极简萌系 Chibi 风格融合，摒弃多余的人形肢体（手与脚），专注呈现木鱼本身的浑圆敦实与敲击趣味：

1. **圆融钝感与亲和力**：外轮廓采用圆角饱满的鹅卵石流线，无任何锋利棱角，传递温和、治愈的视觉感受。
2. **生动交互与生命力**：通过一对灵动的黑白眼瞳与腮红，将冷硬的法器赋予生命，契合 Clawd 的光标视线追踪，让用户工作时有一只静静凝视陪伴的小物灵。
3. **伴生木槌的韵律感**：悬浮木槌作为木鱼的“灵魂伴侣”，在待机、思考、巡逻与敲击中形成节奏互动，使得没有手脚的角色依然拥有极其丰富的动作语言。

## 2. 视觉造型与尺寸基线规范

### 2.1 基础视口与基准坐标
- **画布视口 (`viewBox`)**：`-25 -25 50 50`（统一逻辑尺寸 50×50，中心原点位于坐标 `(0, 0)`）。
- **地面接触线 (`baselineY`)**：`18`。
- **可视包围盒 (`contentBox`)**：`{ "x": -13, "y": -10, "width": 26, "height": 28 }`。
- **中心轴 (`centerX`)**：`0`。
- **桌面窗口高度占比 (`visibleHeightRatio`)**：`0.40`（严格处于黄金舒适区间 `0.38 ~ 0.44`，避免视觉压迫）。
- **底边贴合比率 (`baselineBottomRatio`)**：`0.05`。

## 4. 核心状态动效设计矩阵

| 状态名 | 文件名 | 动作表现与物理节奏细节 | 循环周期 |
|---|---|---|---|
| **待机跟随** | `idle-follow.svg` / `idle.svg` | 木鱼平稳置于地面，微幅呼吸律动（缩放 `1.0 ~ 1.02`）；眼睛接入 `#eyes-js` 跟随光标偏转；伴生小木槌在后方悠闲上下浮动，每隔 2.5 秒触发一次自然眨眼。 | 3.0s (A 类无缝闭环) |
| **漫步巡逻** | `roam.svg` | **Q 弹果冻跳跃（Hop & Squash）**：<br>1. 0%~20%：向下压缩蓄力（Y 轴缩放至 0.85，宽扩至 1.10）；<br>2. 20%~55%：离地腾空跳跃，Y 轴位移至 `-8px`（呈拉伸状，长宽比 1.08:0.92）；<br>3. 55%~80%：落地瞬间重击压缩（Y 轴位移回 0，缩放 0.88）；<br>4. 80%~100%：软弹复位（果冻轻微颤动平滑闭环）。木槌在后方受惯性上下抛物线跟随。 | 1.2s (A 类无缝闭环) |
| **沉浸工作** | `working.svg` | **极速沉浸敲木鱼**：小木槌以 120BPM（0.5s 一击）强劲富有节奏地敲击木鱼头顶；每次击中瞬间，木鱼身体受力微向下扁压（Squash `0.94`），眼睛转为月牙笑眼；头顶迸发金色敲击冲击波圈，并持续升起半透明金色“功德+1”浮空字符飘散。 | 1.0s (双击为一个完整闭环) |
| **思考发呆** | `thinking.svg` | 木鱼身体微向左上方倾斜，眼神呆萌向上仰望；小木槌像钟摆一样在头顶轻轻左右微摇；头顶升起 3 个淡金色佛系气泡与一个小问号，轻盈破灭。 | 2.4s (A 类无缝闭环) |
| **入睡打鼾** | `sleeping.svg` | 木鱼贴在地面整体呈现压扁软瘫状（高度 `0.85`），眼睛闭合成两道平缓弧线；小木槌平倒横卧在身旁轻轻震颤；木鱼伴随深沉的鼾声节奏平缓起伏，头顶有节奏地冒出渐隐飘动的“z Z Z”小气泡。 | 3.6s (A 类无缝闭环) |
| **系统通知** | `notification.svg` | **金光大作急促敲击**：木槌以三倍速急速狂敲，木鱼全身发出耀眼的金色佛光轮廓脉冲，正上方爆开大号发光字符“功德+999”并在空中爆裂展开为闪光粒子，双眼兴奋大睁。 | 1.5s 循环或单次 |
| **异常状态** | `error.svg` | 木鱼双眼变成小叉叉（`× ×`）并轻微左右颤抖；小木槌不小心失手歪倒磕在地上；头顶飘起一缕淡淡的小乌云或灰色叹息青烟。 | 1.8s (平滑降级) |
