# 小兔子 R6.0 设计与技术方案

> **原始需求与背景回溯**：
> - **提出时间**：2026-09-18
> - **业务场景**：`pet-forge` 为动画制作开源工坊，`clawd-on-desk`（本地路径 `E:\Work2\AI_Work\tool\clawd-on-desk\clawd-on-desk\clawd-on-desk`）为桌面宠物运行时。项目下已有 `R1_doraemon`、`R2_clock`、`R3_dabaixiong`、`R4_GIRL`、`R5_labixiaoxin`。当前需要在 `work_space/R6_xiaotuzi/` 下，以用户提供的参考图片（拟人化毛茸茸帅气小兔格斗少年）为基准，采用 **APNG 路线** 制作高品质桌面宠物动画素材。
> - **用户原始诉求**：“项目下，我想按照APNG 路线方式，按照这张图片上的角色生成动画素材，在R6_xiaotuzi下，专门用于开源项目E:\Work2\AI_Work\tool\clawd-on-desk\clawd-on-desk\clawd-on-desk使用。你需要看下R1_doraemon，以及开源项目。然后告诉我步骤，并生成R6.0的方案和计划。你需要给我生成每个动画的提示词，我去用豆包生成适配后，提供给你。需要生动有趣”。
> - **已拍板技术决策**：
>   1. **APNG 位图动图路线**：突破传统的纯 SVG 代码绘制路线，采用高质量、高细节的 AI 渲染与透明带 Alpha 通道的 APNG（Animated PNG）动图格式，完美呈现毛发质感、服饰褶皱与生动立体的 3D/日漫风光影。
>   2. **运行时通道对接**：经深入核验 `clawd-on-desk` 源码，其内置双通道渲染体系：SVG 走 `<object>` 通道，而 APNG/GIF/WebP 走纯净的 `<img>` 渲染通道；`animation-cycle.js` 内置 `probeApngCycle` 自动探测 APNG 帧持续时间与循环时长；在 `theme.json` 中配置 `eyeTracking.enabled: false`（位图不支持 SVG 挂点眼动，表情动作直接由 AI 烘焙生成）。
>   3. **尺寸基线与视口控制**：采用标准规范画布尺寸（如逻辑视口 `256×256`），严格锁定 `visibleHeightRatio: 0.42` 与 `baselineBottomRatio: 0.05`，保证角色在桌面端维持最舒适的黄金视觉占比，避免遮挡用户工作屏幕。
>   4. **漫步方向与循环闭环**：`roam.apng` 统一保持**面朝右侧 (Facing Right)**，Clawd-on-desk 向左漫步时会自动进行水平镜像翻转；循环状态动画（`idle`, `roam`, `working`, `thinking`, `sleeping`）必须做到首尾关键帧 100% 连贯，实现无缝平滑循环。
>   5. **核心状态矩阵交付**：覆盖 7 大核心状态（`idle`, `roam`, `working`, `thinking`, `sleeping`, `notification`, `error`）。
> - **对接运行时**：Clawd-on-Desk (`theme.json` Schema v1)
> - **交付目标**：`work_space/R6_xiaotuzi/`

## 1. 方案概述与角色设计哲学

1. **头部与面部**：
   - **高耸竖耳**：一双修长挺拔的野兔耳朵，外侧为浅米黄色柔毛，内侧为温暖粉嫩的渐变色，耳尖带有灵动的微弧度。
   - **凌厉金瞳**：黄色/琥珀色锐利眼瞳，微微上挑的深色眼线，眼神机警自信，嘴角微翘，带有一丝小傲娇与酷拽。

2. **服饰与躯干**：

3. **动作性格特征**：
   - **生动、敏捷、元气、酷帅**：拒绝呆板静止，动作富有弹簧般的爆发力（Squash & Stretch）与野兔特有的机敏抽搐、转耳、眨眼。

## 2. APNG 路线与 SVG 路线的架构对比

| 维度 | R1_doraemon (全 SVG 路线) | R6_xiaotuzi (APNG 路线) |
|---|---|---|
| **资产载体** | 矢量 XML 代码 (`.svg`) | 透明背景动态位图序列 (`.apng`) |
| **视觉呈现** | 扁平几何色块、描边、轻量渐变 | 超写实 3D 毛发质感、真实光影、细腻褶皱与动态粒子 |
| **Clawd 渲染通道** | `<object>` 挂载，DOM 可直接操纵 | `<img>` 标签纯净硬件加速渲染 |
| **眼球光标跟随** | 启用 `#eyes-js` 挂点计算实时偏移 | 禁用 `eyeTracking.enabled: false`（AI 烘焙灵动眼部动态） |
| **循环周期检测** | 解析 SVG 内部 CSS/SMIL 持续时间 | `animation-cycle.js` 的 `probeApngCycle` 自动探测帧时间 |
| **制作生产方式** | 手工分层矢量绘制 + CSS Keyframes | 豆包 AI 生成生动视频/序列帧 -> 透明去底 -> 压制优化 APNG |

## 5. 豆包 AI (Doubao) 生成提示词工程库

为了确保在豆包中生成的动画具有**角色一致性（与参考图一致）**、**动作生动性**以及**后续 APNG 抠图透明化的便利性**，建议在豆包中使用以下策略：
1. **垫图**：上传本工程提供的 `work_space/R6_xiaotuzi/00_reference/rabbit_reference.jpg` 作为角色形象一致性参考图（设置高角色还原度/形象一致性）。
2. **纯色背景约定**：统一要求“纯白色纯净背景”或“纯绿色绿幕背景”，方便后续工具批量自动去底透明化。
3. **固定机位与无镜头运动**：必须强调“固定摄像机机位，无缩放，无平移，全身居中无遮挡”，防止桌面宠物在窗口内晃动错位。
