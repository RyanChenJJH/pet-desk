## Global Constraints

1. **全 SVG 自包含硬性约束**：所有交付产物必须是自包含 SVG，严禁任何 `<script>` 标签或外部 `<link>` / `<image>` 引用。
2. **Clawd 光标跟随接口标准**：`idle-follow.svg` 必须暴露 `#eyes-js`, `#body-js`, `#shadow-js` 元素 ID，基准坐标系严格保持 `viewBox="-25 -25 50 50"`。
3. **动画闭环无跳帧**：所有持续循环状态（A 类动画）的 `@keyframes` 0% 与 100% 变换属性必须绝对一致。
4. **漫步方向统一**：`roam.svg` 角色本体必须绘制为面向右侧（Facing Right）。
5. **编码硬约束**：`theme.json` 必须保存为纯 UTF-8 无 BOM 格式。
6. **严禁占位符（No Placeholders）**：所有任务与步骤必须包含完整的可执行代码与明确的验证命令，杜绝任何 TBD/TODO。

```powershell
$svgFiles = Get-ChildItem "e:/Work2/AI_Work/tool/clawd-on-desk/pet-forge/work_space/R3_dabaixiong/theme/assets/*.svg"
$allPassed = $true

Write-Host "=== 开始执行大白熊 R3.0 全局铁律契约检查 ===" -ForegroundColor Cyan

foreach ($file in $svgFiles) {
    $content = Get-Content $file.FullName -Raw
    
    # 1. 严禁 script 标签
    if ($content -match "<script") {
        Write-Error "FAIL: $($file.Name) contains <script> tag!"
        $allPassed = $false
    }
    
    # 2. 严禁外部资源 (<link>, <image>, @import, url(http...))
    if ($content -match "<link" -or $content -match "<image" -or $content -match "@import" -or $content -match "url\s*\(\s*['""]?https?://") {
        Write-Error "FAIL: $($file.Name) contains external resource links!"
        $allPassed = $false
    }
    
    # 3. 必须包含 viewBox
    if ($content -notmatch 'viewBox="-25 -25 50 50"') {
        Write-Error "FAIL: $($file.Name) viewBox is not -25 -25 50 50!"
        $allPassed = $false
    }
    
    Write-Host "✓ $($file.Name) 纯净自包含与坐标系校验通过" -ForegroundColor Green
}

# 4. 验证 idle-follow 的跟随 ID
$idleContent = Get-Content "e:/Work2/AI_Work/tool/clawd-on-desk/pet-forge/work_space/R3_dabaixiong/theme/assets/idle-follow.svg" -Raw
```
