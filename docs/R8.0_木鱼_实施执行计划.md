# 木鱼 R8.0 实施执行计划（正宗法器整改版）

> **原始需求与背景回溯**：
> - **提出时间**：2026-09-20
> - **整改背景**：用户体验初版后提出明确优化要求：
>   1. **造型不像木鱼**：需摒弃低幼圆球，完美还原正宗佛教传统经典法器木鱼形制；
>   2. **彻底取消眼睛**：去除任何拟人化眼部设计，呈现纯净古朴禅意法器；
>   3. **静态展示常态敲击**：待机（`idle`）状态下即为木鱼常态敲击，小木槌有节奏叩击，侧旁伴随敲击浮现显示 “+1”，然后慢慢升腾消散。
> - **对接运行时**：Clawd-on-Desk (`theme.json` Schema v1)
> - **交付目标**：`work_space/R8_wooden_fish/`

---

## 全局约束与红线

1. **绝对禁止 UTF-8 BOM**：所有 `.json` 与 `.svg` 文件保存为纯 UTF-8 编码。
2. **纯净沙箱**：严禁 `<script>` 标签与外部网络资源。
3. **首尾帧闭环**：A 类循环动效 0% 与 100% 严格一致。
4. **固定尺寸基线**：`viewBox="-25 -25 50 50"`，`visibleHeightRatio: 0.40`，`baselineBottomRatio: 0.05`。
5. **Git 自动化推送**：完成后自动 commit 并 push 至远端仓库 `main` 分支。

---

- [ ] **步骤 1: 重构分层矢量母版 (`wooden-fish-master.svg`)**
  - 绘制朱红金丝锦缎蒲团底座（椭圆立体垫、金黄滚边如意纹）。
  - 绘制正宗法器木鱼主体（深红木/紫檀温润质感、马蹄拱形鱼腹共鸣腔）。
  - 绘制贯穿正面与侧面的镂空发音横槽（双端共鸣扩孔）。

  - 绘制后部镂空卷尾提梁握柄。
  - 彻底移除任何眼睛与面部五官。
  - 绘制伴生敲击木槌（长柄束带圆木槌）。

- [ ] **步骤 2: 重新精修制作 7 大状态动画 SVG**
  - **`idle-follow.svg`**：静态展示常态敲击（1.6s 舒缓安神节奏），木槌沉稳叩击木鱼头顶，木鱼在蒲团上微沉下陷回弹，侧上方升腾半透明金色 “+1” 渐隐飘散，附带淡金音波涟漪。
  - **`roam.svg`**：面向右侧（Facing Right），木鱼端坐朱红锦缎蒲团上轻盈仙气悬浮滑行，木槌惯性随行。
  - **`working.svg`**：双倍速（0.8s 周期）高频密集沉浸敲击，接连不断升腾 “+1” 字符与连续金色震波。
  - **`thinking.svg`**：木槌停敲并在头顶如钟摆般轻慢打转，头顶升起 3 个淡金禅意气泡与发光小问号。
  - **`sleeping.svg`**：木槌横卧在蒲团身侧，木鱼在蒲团上深呼吸微幅起伏，头顶冒出漂浮的 “z Z Z”。
  - **`notification.svg`**：急促狂击，朱红蒲团与木鱼周身爆开佛光脉冲与大号 “+999” 闪光字符。
  - **`error.svg`**：木鱼在蒲团上歪倒，木槌跌落磕地，头顶升起委屈青灰叹息烟缕。
