## 全局约束与验收红线 (Global Constraints)

1. **绝对禁止 UTF-8 BOM**：所有 `.json` 与 `.svg` 文件必须保存为无 BOM 的纯 UTF-8 编码。
2. **纯净沙箱**：严禁包含任何 `<script>` 标签，严禁引用外部 CSS、字体或网络图片。
3. **眼动挂点契约**：`idle-follow.svg` 必须保留 `#eyes-js`, `#body-js`, `#shadow-js`。
4. **首尾帧闭环**：A 类循环动画（`idle`, `roam`, `working`, `thinking`, `sleeping`）的 `@keyframes` `0%` 与 `100%` 关键帧的 `transform` 与 `opacity` 必须 100% 严格一致。
5. **固定尺寸基线**：`viewBox="-25 -25 50 50"`，`visibleHeightRatio: 0.40`，`baselineBottomRatio: 0.05`。
6. **Git 自动化推送**：完成后必须自动执行 commit 与 push 至 `origin main`。
