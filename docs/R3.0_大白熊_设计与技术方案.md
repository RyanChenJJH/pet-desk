## 1. 方案概述与角色设计哲学

本方案依据 `pet-forge` 动画工作流及 `clawd-on-desk` 桌宠系统规范，专为用户定制打造兼具“呆萌治愈感”与“爆笑趣味性”的**大白熊**桌面宠物。

### 1.1 角色人设与性格特征
- **外形特征**：软糯如棉花糖般的圆滚滚白色身躯，微尖的可爱小立耳，额前几绺翘起的小呆毛与困惑微汗滴，两颗相隔甚远的呆滞小点眼（`.       .`），粉嫩的倒三角鼻头，微张的粉唇与标志性“倒八字”胡须，双下巴褶皱弧线，身着浅天蓝背带裤。
- **性格标签**：**呆萌、心大、贪吃、打工怨念、容易宕机**。平时是一只慢条斯理、眼神清澈又愚蠢的大白熊；遇到敲代码会残影暴走，遇到难题会 CPU 干烧冒烟，收到通知会惊吓炸毛举饼干，睡起觉来鼻涕泡吹得圆滚滚。

### 1.2 核心技术硬约束（Iron Rules）
- **全纯净矢量（Zero Script & Pure Vector）**：100% SVG 1.1 规范，严禁任何 `<script>` 脚本，严禁外部 `<link>` / 外部图片 / 自定义网络字体。所有动效完全由自包含的 `<style>` 标签与 CSS3 `@keyframes` 驱动硬件加速渲染，CPU 占用极低（<0.6%），高分屏 4K/8K 缩放无损。
- **Clawd 光标跟随契约（Eye-Tracking Rig）**：
  - `#eyes-js`：两颗呆呆的小黑点瞳孔随着用户光标在白白大脸上平滑游移（偏移限制 2.5px 内，不穿模）。
  - `#body-js`：接收微幅身体倾角，赋予大白熊软糯的肉感倾侧。
  - `#shadow-js`：地面投影随视角微幅拉伸与平移。
- **循环动画 100% 首尾闭环**：持续循环类动画（`idle`, `roam`, `working`, `thinking`, `sleeping`）的 `@keyframes` 0% 与 100% 变换参数严格一致，严禁任何跳断。
- **漫步统一面朝右侧**：`roam.svg` 角色本体必须绘制为面向右侧（Facing Right），以便运行时自动翻转。
