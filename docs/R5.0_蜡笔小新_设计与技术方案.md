# 蜡笔小新 R5.0 设计与技术方案

> **原始需求与背景回溯**：
> - **提出时间**：2026-09-18
> - **业务背景**：`pet-forge` 为动画制作开源工作坊，`clawd-on-desk` 为本地桌面宠物运行时。项目下已有 `R1_doraemon`（机器猫）、`R2_clock`、`R3_dabaixiong` 与 `R4_GIRL`。当前在 `work_space` 下制作全新的“蜡笔小新”（野原新之助）桌面宠物。
> - **用户原始诉求**：“项目下的R1_doraemon 中，已经做了一个机器猫的桌面宠物动画。现在需要创建R5_labixiaoxin。做一个蜡笔小新的动画。请先给出R5.0方案和计划”。用户于 2026-09-18 对方案与计划回复“同意”。
> - **已拍板技术决策**：
>   1. **全 SVG 路线**：纯自包含 SVG，纯 CSS `@keyframes` 硬件加速动画，零 `<script>`，零外部依赖，100% 契合 Clawd-on-desk 安全沙箱规范。
>   2. **视觉造型基线**：以经典红衣黄裤（Red T-shirt & Yellow Shorts）经典常服为造型标准，还原标志性波浪粗眉、肉嘟嘟右脸颊与呆萌大圆眼。
>   3. **尺寸标准对齐**：严格执行 `AGENTS.md` 固定尺寸基线（`viewBox="-25 -25 50 50"`，`visibleHeightRatio: 0.42`，`baselineBottomRatio: 0.05`，`baselineY: 16`）。
>   4. **交付范围**：聚焦 6 大 MVP 核心状态（`idle`, `roam`, `working`, `thinking`, `notification`, `sleeping`）。
>   5. **文档命名与存储**：统一存储于 `work_space/docs/`，采用标准中文命名（`R5.0_蜡笔小新_设计与技术方案.md` 与 `R5.0_蜡笔小新_实施执行计划.md`）。
> - **对接运行时**：Clawd-on-Desk (`theme.json` Schema v1)
> - **交付目标**：`work_space/R5_labixiaoxin/`

## 1. 方案概述与角色设计哲学

蜡笔小新（野原新之助）具有极强的人物个性与极高的国民级辨识度。本方案遵循 `pet-forge` 规范中“概念图定义角色是谁，母版解决像不像，分层解决能不能动”的核心原则，对小新进行矢量化提取与拟人化桌宠建模。

### 1.1 核心特征保留与提炼
1. **头部与脸型**：标志性“右侧突起肉嘟嘟小腮帮”（横向圆润偏侧造型），短寸平头黑发。
2. **眉眼精髓**：
   - **波浪粗眉**：小新的灵魂所在，两道高辨识度浓黑粗眉，具有生动的起伏波浪感。
   - **大圆眼球与光标跟随**：纯真呆萌的大黑眼珠，内置白色反光高光点，接入 Clawd `#eyes-js` 挂点，实现光标灵动注视。
   - **自然微红腮红**：脸颊两侧带有一抹可爱淡粉腮红。
3. **服饰与躯干**：
   - 上身：经典高饱和度红圆领短袖 T 恤，小圆肚子微微凸起。
   - 下身：黄色直筒小短裤，露出肉嘟嘟的小腿与圆圆的小蓝鞋。
4. **动作性格**：兼具“呆萌”、“调皮”与“自信”，动画节奏轻快富有弹性（Rubber-hose / Anime timing）。

## 3. 分层矢量母版契约 (`shinchan-master.svg`)

母版是所有状态动画的唯一真实源（Single Source of Truth），严格使用居中视口与标准挂点。

### 3.1 视口与包围盒基线
- **`viewBox`**：`-25 -25 50 50`（统一逻辑空间 50×50，中心点 `(0, 0)`）
- **`contentBox`**：`{"x": -12, "y": -12, "width": 24, "height": 28}`
- **`centerX`**：`0`
- **`baselineY`**：`16`（脚底贴地线，地面投影 `Y = 16.5`）
- **`visibleHeightRatio`**：`0.42`（完美契合桌面端舒适占比）
- **`baselineBottomRatio`**：`0.05`

### 3.2 图层结构与骨骼挂点（Z-Order 从底到顶）
1. **`#shadow-js`**：地面椭圆投影（`cx="0" cy="16.5" rx="10" ry="2.2"`）。
2. **`#body-js`**：躯干与头部整体驱动层：
   - **`legs`**：黄色短裤、肉色小腿与圆头小蓝鞋。
   - **`torso`**：微鼓小腹、红色 T 恤外壳。
   - **`arms`**：左手、右手短袖管与肉色小手。
   - **`head`**：平头短发、肉嘟嘟鼓脸颊、两只圆耳朵与可爱粉腮红。
   - **`eyebrows`**：两道标志性波浪浓粗眉。
   - **`mouth`**：俏皮弧线微笑。
   - **`#eyes-js`**：大黑圆眼球与纯白高光点（`transform-origin: 0px -2.5px`）。
