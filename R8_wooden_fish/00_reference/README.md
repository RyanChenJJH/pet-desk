# 木鱼（Wooden Fish）R8.0 参考规范与设计备忘

## 1. 角色基本信息
- **代号**：R8.0
- **角色名**：木鱼（Wooden Fish）
- **类型**：纯木鱼桌宠（无手无脚，带悬浮伴生小木槌）
- **定位**：呆萌解压、功德积攒、桌面治愈伴侣

## 2. 尺寸与基准规范 (Baseline)
- **viewBox**：`-25 -25 50 50`（居中原点 `(0, 0)`）
- **contentBox**：`{ "x": -13, "y": -10, "width": 26, "height": 28 }`
- **centerX**：`0`
- **baselineY**：`18`
- **visibleHeightRatio**：`0.40`（红线范围：0.38 ~ 0.44）
- **baselineBottomRatio**：`0.05`

## 3. 色板定义 (Warm Sandalwood Palette)
- **木鱼亮面高光**：`#F59E0B`
- **木鱼温润主体**：`#D97706`
- **木鱼阴影底色**：`#B45309`
- **鱼嘴缝隙 / 雕花**：`#78350F`
- **轮廓硬边描边**：`#3C1A06`（线宽 0.8px）
- **腮红**：`rgba(244, 63, 94, 0.45)`
- **眼眶瞳孔**：`#18181B`
- **小木槌材质**：`#92400E` / `#B45309`
- **功德金色光效**：`#FBBF24` / `#FEF3C7`
- **地面投影**：`rgba(60, 26, 6, 0.18)`

## 4. 骨骼图层挂点契约
- `#shadow-js`：地面柔和椭圆阴影，中心 (0, 18)
- `#body-js`：木鱼整体躯干与形变挂点，中心 (0, 18)
  - `#fish-body`：圆滚木鱼外壳与雕纹
  - `#eyes-js`：光标跟随眼球挂点，中心 (0, 5)，最大位移 2.0px
  - `#blush`：两颊微醺粉色腮红
- `#mallet-js`：悬浮伴生小木槌，旋转轴心 (8, -2)
- `#effects-js`：浮空金色功德与光环特效
